기술

데이터 수집 · 정제 · 분석

API를 통한 대량 키워드 데이터 수집부터 결론 도출까지 전 과정을 단독 수행. 네이버 검색광고(SA) API로 절대검색량을, DataLab API로 상대 검색추이를 수집해 두 지표를 교차 검증하는 통합 분석 프로세스를 설계했으며, HMAC 서명 인증을 직접 구현해 운영 중. 수집 데이터를 고객 상황 단위 세그먼트로 정제하고, 세그먼트별 전환 성과를 서치어드바이저 지표(노출·클릭·CTR)로 역추적해 키워드 포트폴리오를 재조정하는 사이클을 운영.

타겟 마케팅 전략 수립 및 집행

도출한 세그먼트를 콘텐츠·랜딩페이지·검색광고로 집행하고 전환 성과를 측정하는 전 과정을 담당. 유입-탐색-전환 3단계 퍼널을 설계하고 전환 지점에 리드 수집을 배치해 트래픽을 고객 DB로 전환. 웹 서비스 3종에서 90일 기준 노출 6.9만 회·클릭 1,570회를 확보했으며, CTR 편차(0.2%~12.6%)를 분석해 고전환 지면에 자원을 재배분.

보험 · 금융 도메인 및 온라인 영업전략

생명·손해 32개 보험사 상품 비교 분석 및 고객 재무상황별 보장 포트폴리오 설계. 온라인 영업전략을 수립·집행해 46개월간 보유계약 402건·합계보험료 6억 3,663만 원 달성. 약관·특약·부지급 판례 분석 기반 보험금 분쟁 대응 수행. 금융소비자보호법 준수 마케팅 체계 수립 경험 보유.

교육 · 지식 전달

복잡한 규제·세법 데이터를 비전문가가 의사결정 가능한 형태로 구조화해 전달한 경험 보유. 5세대 실손보험 출시 및 세대별 재가입 주기 안내 11p, 저축성보험 비과세요건 정리자료 7p 사내교육·고객안내 자료 제작, 상속·증여 세법을 7개 고객 케이스로 재구성한 27p 교육자료, 토지 가치분석 54p 강의자료. 입사 6개월 시점 성과를 인정받아 전국 지점 송출 교육에 일일 강사로 참여한 이력 보유. 분석 결과를 조직이 실행 가능한 형태로 이전하는 역량.

AI 활용 및 업무 자동화

Claude Code 기반 바이브코딩으로 마케팅에 필요한 웹 서비스를 직접 구현. 7단계 멀티에이전트 콘텐츠 파이프라인을 설계해 콘텐츠 생산·검토 리소스를 90% 감축. Claude·Gemini·ChatGPT·NotebookLM을 업무 성격별로 분리 활용하여 약관 분석, 콘텐츠 생성, 상담자료 작성 프로세스를 표준화.

부동산 · 공공데이터

도시부동산기획경영학 복수전공 및 경매 실무 과정 이수. 등기부등본 권리분석, 용도지역·공법상 규제 검토, 실거래 데이터 기반 물건 가치 평가 수행. 공공데이터포털 API를 활용한 전국 부동산 실거래가 데이터 추적 및 분석 콘텐츠 발행. API를 활용한 병원·약국 데이터 수집·정제·서비스화 경험 보유.
